# Product Requirements Document


## Problem

[Who has the problem? What is difficult for them today? Alternatively, what need do you see this fulfilling in which user group?]
Me and anyone who can't/forgets to plan for birthday presents 

## Desired outcome

[What should be better or more interesting for users when this is done?]
planning birthday presents should be easier and more streamlined

## Scope

[Which users, use cases, and features will this app cover?]
anyone who needs to plan/budget for birthday presents/present ideas

## Out of Scope

[What features is this app specifically avoiding?]
outside influence (i.e. online access), should be completely self contained and offline

## Requirements
Needs to budget for money
Needs to put that budget into a document
Needs to display that document on the screen using python ui libraries 

### The product must

- Accept and input for name, date of birthday, present ideas, and how much those presents cost

### The product should

- display that info in a streamlined fashion, in the background and the foreground when focused.

### The product could

- Include formatting options for the displayed information.
